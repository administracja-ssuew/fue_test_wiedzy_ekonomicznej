# Technology Stack

**Analysis Date:** 2026-04-23

## Languages

**Primary:**

**Secondary:**

- HTML5 - Meta tags and PWA configuration in `index.html`

## Runtime

**Environment:**
- Node.js (version not specified in package.json)

**Package Manager:**
- npm
- Lockfile: `package-lock.json` (present)

## Frameworks

**Core:**
- React 18.3.1 - UI framework
  - ReactDOM 18.3.1 - DOM rendering
  - Used in `src/main.jsx` entry point via `createRoot()` and `StrictMode`
  - All UI components are React functional components with hooks

**Build/Dev:**
- Vite 5.4.8 - Development server and production bundler
  - Config: `vite.config.js`
  - React plugin: `@vitejs/plugin-react` 4.3.1
  - Build scripts in `package.json`:
    - `npm run dev` - Vite dev server
    - `npm run build` - Production build
    - `npm run preview` - Preview built output

**PWA:**
- vite-plugin-pwa 0.21.1 - Progressive Web App capabilities
  - Auto-registers service worker (registerType: 'autoUpdate')
  - Manifest configured for standalone app with theme color `#6B21E8`
  - Icons configured in `public/` directory: `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`
  - Workbox caching configured for Google Fonts (CacheFirst strategy, 1-year expiration)

## Key Dependencies

**Critical:**
- @supabase/supabase-js 2.45.0 - Backend-as-a-service for auth and database
  - Imported in `src/lib/supabase.js`
  - Handles user authentication, profile management, quiz sessions, and attempt tracking
  - Supports demo mode with localStorage fallback when Supabase credentials missing

## Configuration

**Environment:**
- Vite configuration: `vite.config.js`
  - Defines plugin stack (React, PWA)
  - PWA manifest configuration with app metadata
  - Workbox runtime caching for Google Fonts

**Environment Variables:**
- `.env` file (present, not tracked by git)
- `.env.example` exists for reference
- Required variables (from `.env.example`):
  - `VITE_SUPABASE_URL` - Supabase project URL
  - `VITE_SUPABASE_ANON_KEY` - Supabase anonymous/public key

**Conditional Demo Mode:**
- App switches to localStorage-based demo mode when Supabase credentials are missing
- Controlled by `DEMO` constant in `src/lib/supabase.js` line 6
