# Plan 02-04: UI Wiring — Session Code, Admin Auth, Participant Join

## Objective

Wire the existing UI screens to real Supabase data: remove hardcoded admin password, show 6-digit join code after session creation, add participant join-by-code flow in Lobby, display Pending screen for unverified users.

## Context

- All screens already exist from Phase 1 — this plan modifies them, not creates them
- `AdminLogin.jsx` currently checks for hardcoded "FUE2025" — replace with real `loginUser()`
- `AdminPanel.jsx` currently calls `startQuiz` from App props — must show `join_code` after session creation
- `Lobby.jsx` currently shows a lobby for participants already in session — add join-by-code input
- All auth state comes from `useAuth` hook via App.jsx props
