`formatCodeInput(raw, prev = "")` — implementacja z researchu (Wzorzec 5):
```js
const up = String(raw ?? "").toUpperCase();
const clean = up.replace(/[^A-Z0-9]/g, "");
const [, letters, rest] = clean.match(/^([A-Z]{0,3})(.*)$/);
const digits = rest.replace(/\D/g, "").slice(0, 6);
if (letters.length < 3) return letters;
const deleting = up.length < String(prev ?? "").length;
if (!digits) return deleting ? letters : `${letters}-`;
return `${letters}-${digits}`;
```
(„K1” → litery „K”, reszta „1” → zwraca „K”, bo letters < 3.)

`parseCodesCsv(text, { prefix, city, takenNumbers = new Set() })`:
- `String(text).replace(/^\uFEFF/, "")`, `split(/\r?\n/)`; indeks linii `i` → `line = i + 1`.
- Pusta po trim → pomiń. Komórki: `row.split(/[;,]/).map((p) => p.trim().replace(/^["']|["']$/g, ""))`.
- Nagłówek: pierwsza niepusta linia, której pierwsza komórka po `toLowerCase()` to „imię” albo „imie” → pomiń.
- `name = cells[0] || ""`, `surname = cells[1] || ""`, `raw = (cells[2] || "").trim()`; `display = \`${name} ${surname}\`.trim()`.
- Brak imienia/nazwiska → `{ line, name: display, reason: "brak imienia lub nazwiska" }`.
- Kod: zdejmij `="…"` (`/^=\s*"?(.*?)"?$/`), trim. Pusty → `number: null`. Postać z literami `/^([A-Za-z]{3})-?(\S+)$/`: litery (upper) ≠ prefix → reason `` `kod ${L}-${rest} należy do innego miasta` ``; inaczej `rest` jako numer. Numer ≠ `/^\d{4}$/` → reason `` `kod „${rawCell}” musi mieć 4 cyfry` `` + gdy `/^\d{1,3}$/` dopisek `" — jeśli w Excelu zniknęły zera z przodu, sformatuj kolumnę Kod jako Tekst"` (`rawCell` = komórka po zdjęciu `="…"`).
- Duplikaty: po pierwszym przebiegu zgrupuj poprawne numery; numer w ≥ 2 wierszach → wszystkie te wiersze przenieś do błędów z reason `` `kod ${prefix}-${nnnn} powtarza się w pliku (wiersze ${joinLines(lines)})` ``.
- Zajęte: `takenNumbers.has(nnnn)` → reason `` `kod ${prefix}-${nnnn} jest już zajęty w mieście ${city}` ``.
- Kolejność sprawdzeń: imię/nazwisko → format/prefiks → duplikat → zajęty. `errors` posortowane po `line`.

`pickFreeNumbers(n, taken, rng = cryptoRandomInt)`: pula wolnych = 0..9999 bez `taken` (padStart 4); losowanie bez zwracania (Fisher–Yates częściowy) z `crypto.getRandomValues` (fallback `Math.random`); gdy wolnych < n → zwróć tyle, ile jest. `assignNumbers(valid, taken, rng)`: `used = new Set([...taken, ...valid.filter(v => v.number).map(v => v.number)])`; dla wierszy z `number === null` przydziel kolejne z `pickFreeNumbers(countNull, used, rng)` i ustaw `random: true`. `takenNumbersFromCodes(codes, prefix)`: kody `^${prefix}-(\d{4})$`. `normalizeParticipantCode(raw)`: `const f = formatCodeInput(raw); return CODE_RE.test(f) ? f : null;`.
