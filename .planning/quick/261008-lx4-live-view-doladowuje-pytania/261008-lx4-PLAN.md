# 261008-lx4: Live View doładowuje pytania

## Problem

Pomiar 08.10.2026 (`report/s261008-1-full-live.log`) potwierdził bug: `useLiveProjection`
pobiera `getQuestions(city)` tylko przy otwarciu projektora. Pytanie dodane albo
podmienione po otwarciu → `findIndex` po `v.item.id` zwraca -1 → fallback `v.idx`
pokazuje pytanie spod złego indeksu lokalnej listy (złą treść i zły numer).
Dodatkowo numer i licznik ("Pytanie 3/12") liczone są z lokalnej listy pytań miasta,
a nie z planu sesji, więc rozjeżdżają się, gdy lista ≠ plan.

## Task 1: hook - doładowanie pytań i numer z planu

`src/hooks/useLiveProjection.js`:
- `refreshQuestions()` - `getQuestions(city)` z blokadą równoległych wywołań i
  odstępem min. 2 s; po odpowiedzi aktualizuje `questions` i `questionsRef`.
- `applySession`: przy pobraniu planu nowej sesji doładuj też pytania.
- `tickPlan`: gdy id z planu nie ma na liście → `refreshQuestions()` i `gIdx = -1`
  (brak `currentQ`, ekran nie pokazuje cudzego pytania); bez fallbacku `v.idx`.
- Zwracaj `qNum` (`v.idx + 1`) i `qTotal` (liczba pozycji planu), `mod` z
  `currentQ.module` albo z `item.m` planu.

## Task 2: ekrany - numer z planu

`src/screens/LiveView.jsx`, `src/screens/AdminPanel.jsx` (LiveTab):
`{gIdx + 1}/{questions.length}` → `{qNum}/{qTotal}`.

## Verify

- `npx vitest run` - bez regresji
- `npm run build` - przechodzi
- Przegląd: przy id spoza listy `currentQ` jest `undefined`, po doładowaniu wraca.

## Done

Projektor i podgląd admina nigdy nie pokazują pytania spod złego indeksu; nowe pytania
dociągają się same w ≤ ~2-3 s; numer pytania zgodny z planem sesji.
